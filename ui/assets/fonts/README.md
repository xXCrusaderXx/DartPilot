# Bundled fonts

Both faces are licensed under the SIL Open Font License 1.1; each folder holds its licence as `OFL.txt`, and the app
shows both on its licence page. Only the weights the app uses are bundled.

| Folder | Family | Version | Source | Files |
|---|---|---|---|---|
| `barlow-condensed/` | Barlow Condensed, by Jeremy Tribby | 1.422 | <https://github.com/jpt/barlow>, tag `1.422`, `fonts/ttf/` and `OFL.txt` | Medium, SemiBold, Bold |
| `inter/` | Inter, by Rasmus Andersson | 4.1 | <https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip>, `extras/ttf/` and `LICENSE.txt` (saved as `OFL.txt`) | Regular, Medium, Bold |

Barlow Condensed sets scores and big figures on every device. Inter is the text face, unless the player chooses the
system's font in the appearance settings.
